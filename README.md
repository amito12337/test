# TECHNOVA — 4 propositions de design e-commerce

Quatre maquettes de page d'accueil pour la boutique **TECHNOVA** (HTML + CSS uniquement, **aucune logique / aucun JavaScript**). Chaque design est un fichier unique : il suffit d'ouvrir `index.html` dans un navigateur (double-clic) pour le voir.

| Dossier | Style | Inspiration |
|---|---|---|
| `01-electro-salam/` | Boutique électroménager & high-tech classique : rouge/bleu marine, promos, ventes flash, barre de recherche centrale | electrosalam.ma |
| `02-black-shark/` | Boutique gaming sombre : noir + vert néon, formes anguleuses, ambiance e-sport | blackshark.ma |
| `03-technova-minimal/` | Design unique n°1 — premium & épuré : blanc, indigo, beaucoup d'espace, style moderne haut de gamme | Proposition originale |
| `04-technova-vibrant/` | Design unique n°2 — coloré & fun : violet/corail/jaune, style "neo-brutalist" ludique, cible jeune | Proposition originale |

## Notes

- **Images produits** : les visuels sont des emojis de remplacement — à remplacer par de vraies photos produits lors de l'intégration.
- **Polices** : chargées depuis Google Fonts (connexion internet recommandée pour un rendu optimal ; des polices de secours s'affichent hors ligne).
- **Responsive** : chaque maquette s'adapte au mobile et à la tablette.
- **Contenu** : textes, prix (en DH) et avis clients sont fictifs, à titre de démonstration.
